## Project Title

### React Counter App using State Management

---

## Description

This project is a simple React application that demonstrates the concept of components and state management using the `useState` Hook. The application allows users to increase, decrease, and reset a counter value dynamically.

---

## Features

* Increase counter value
* Decrease counter value
* Reset counter value
* Responsive and clean user interface
* Built using reusable React components

---

## Technologies Used

* HTML5
* CSS3
* JavaScript
* React JS
* Babel CDN

---

## Components Used

### Header Component

Displays the title of the application.

### Counter Component

Handles:

* Counter display
* Increase functionality
* Decrease functionality
* Reset functionality

### App Component

Acts as the main component that combines all other components.

---

## State Management

The project uses the React `useState()` Hook for managing the counter value.

Example:

```javascript
const [count, setCount] = React.useState(0);
```

* `count` stores the current value
* `setCount()` updates the value dynamically

---

## Event Handling

The application handles button click events using React functions.

### Increase Button

```javascript
setCount(count + 1)
```

### Decrease Button

```javascript
setCount(count - 1)
```

### Reset Button

```javascript
setCount(0)
```
